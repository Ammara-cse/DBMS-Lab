# 🗄️ Database Management Systems (DBMS) Lab Practicals

This repository contains SQL scripts, relational database queries, schema configurations, and trigger implementations for the **DBMS Laboratory** course.

---

## 🛠️ Tech Stack & Environment
* **Database Engine:** MySQL / Oracle SQL / PostgreSQL
* **Tool / Interface:** Command Line Client / MySQL Workbench / phpMyAdmin

---

## 📋 List of Practical SQL Scripts

| File Name | Topic / Description | Focus Areas |
| :--- | :--- | :--- |
| `00_practical one.pdf` | **Lab Manual / Overview** | Practical instructions & lab problem statements |
| `01_CreateTables.sql` | **DDL Operations** | `CREATE TABLE`, Primary Keys, Foreign Keys & Constraints |
| `02_Insert_Delete_Alter_Drop.sql` | **Data & Schema Modification** | `INSERT INTO`, `DELETE`, `ALTER TABLE`, `DROP TABLE` |
| `03_SELECT_WHERE.sql` | **Data Querying** | Basic `SELECT` statements and conditional `WHERE` filters |
| `04_Rename.sql` | **Table & Column Renaming** | Renaming tables and column aliases |
| `05_Self_Join.sql` | **Self Join Queries** | Joining a table with itself for hierarchical data |
| `06_String_Operations.sql` | **String Functions** | `CONCAT`, `SUBSTRING`, `LENGTH`, `UPPER`, `LOWER` |
| `07_Order_By.sql` | **Sorting Data** | Ordering query results (`ASC`, `DESC`) |
| `08_Where_Clause_Predicates.sql` | **Advanced Filtering** | `LIKE`, `IN`, `BETWEEN`, `AND`, `OR`, `NOT` predicates |
| `09_Set_Operations.sql` | **Set Theory Queries** | `UNION`, `UNION ALL`, `INTERSECT`, `MINUS` / `EXCEPT` |
| `10_Null_Values.sql` | **Handling NULLs** | `IS NULL`, `IS NOT NULL`, `COALESCE`, `IFNULL` |
| `11_Aggregate_Functions.sql` | **Aggregation & Grouping** | `COUNT`, `SUM`, `AVG`, `MIN`, `MAX`, `GROUP BY`, `HAVING` |
| `12_Nested_Subqueries.sql` | **Subqueries** | Correlated & Non-correlated subqueries, `EXISTS`, `IN` |
| `13_Joined_Relations.sql` | **Relational Joins** | `INNER JOIN`, `LEFT JOIN`, `RIGHT JOIN`, `FULL OUTER JOIN` |
| `14_Views.sql` | **Database Views** | Creating, Updating, and Dropping virtual tables (`VIEWS`) |
| `15_Student_Result_Trigger.sql` | **Automated Result Calculation** | Database Trigger for student grade/result logic |
| `15_Triggers.sql` | **PL/SQL Triggers** | `BEFORE` and `AFTER` triggers (`INSERT`, `UPDATE`, `DELETE`) |
